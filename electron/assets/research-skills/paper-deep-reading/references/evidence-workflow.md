# 素材、证据与内容标准

## PDF 素材流程

```sh
python3 scripts/prepare_pdf.py inspect paper.pdf --out work/source --render-pages 2,4,8
python3 scripts/prepare_pdf.py crop paper.pdf --page 2 --box 40,60,560,430 --out assets/figure-1.png
```

页码从 1 开始；裁剪坐标单位为 PDF point，左上为原点。先查看整页渲染，再决定边界；包含图例和轴标签，图注可随图或作为正文单独存储。脚本只定位图注候选，不声称自动准确分割图表。扫描件的文本可能为空，需要另行 OCR 并核对，不能把空文本当作没有内容。

`inventory.json` 记录页尺寸、文本文件、图注候选及其边界；为候选补充 `decision`、`reason`、`asset`、`section` 与双语解读后保存 `asset-plan.json`。同页多图必须逐一核对，整页截图不替代清晰原图。用 PDF 渲染可保留矢量文字，不运行论文代码或 PDF 内嵌动作。

## 四个研究视角

| 章节 | 必须解决的问题 | 优先使用的素材 |
|---|---|---|
| Related work | 真正瓶颈、最近的前驱、本文具体改变、比较是否公平；区分作者定位与外部核实 | 原文对比图、相关工作维度表、引用来源 |
| Method | 输入输出、状态/变量、架构、模块内部步骤、目标函数、约束、设计取舍、可实现性 | 总架构原图、局部原图、公式、伪代码、针对机制的过程图 |
| Experiments | 数据/划分、模型/预算、硬件、指标方向、主结果、消融、失败、开销、统计不确定性 | 主结果图表、消融图表、带来源的结构化数值 |
| Limitations | 作者明确限制、证据导出的疑问、泛化/安全/成本边界、复现缺项、能推翻结论的测试 | 失败例、边界示意、风险与验证实验表 |

每个重要图表的解读回答：看什么、怎么读、支持什么、不支持什么。每项主要贡献应能指向至少一处方法说明与证据；无实验证据的贡献明确标注其性质。无需为理论论文强造实验或凑图。

## 覆盖与证据记录

生成前维护简短覆盖表：`主张 → 对应段落 → 图/表/公式 → 页码 → 可信范围 → 未解决问题`。正文写来源，内部记录可放 `report.json.coverage`。同一数据集的不同指标、模型、预算不能合并成一个不明口径的平均数。可视化保留原始精度、单位和方向；图中未给出的点不能插值冒充实验。

## 内容密度

完整精读应比摘要更深入：模块讲解、实验解释、相关工作定位、复现条件、限制和八问均有实质内容。重点图旁先提供能独立理解的解释，再按需展开技术细节。不要靠重复段落、额外装饰或硬性字数填充。自动字数统计仅供提示，不能证明质量。
