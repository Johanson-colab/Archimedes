# Research SSH workspace (preview)

Research conversations can use a local Codex session with a saved SSH server. Add the server in the existing SSH server settings, select Codex and Research, then select the server in the composer. Use an approval-enabled Codex permission mode. Existing Codex chats created without the SSH tool need a new Research conversation.

Codex runs on the local machine and retains its native conversation, context and permission handling. When asked to work remotely, it can call the `ssh_remote_read`, `ssh_remote_edit` and `ssh_remote_exec` dynamic tools. File reads are limited to 200 lines and 24 KiB per call. Edits operate on an existing UTF-8 file up to 1 MiB and require a unique exact match; the approval shows the old and new text. Creating files and other operations use the command tool. File tools require Python 3 on the remote host. Each operation displays its target, directory and action for approval before execution. Codex's ordinary file and shell tools still operate locally; this is not transparent redirection of all native tools. The selected server resets when opening a different conversation and must be selected again.

Remote commands are not Archimedes-managed experiment Runs and do not automatically create Research Graph evidence. Reproduce remains separate. Commands time out after 60 seconds and their output is bounded; cancellation, timeout or a connection failure does not prove that the remote process stopped. Inspect the server before retrying. Persistent SSH connection reuse, automatic reconnection, long-running job management, remote run tracking and reproducible snapshots are not implemented here. Host-key behavior follows the existing SSH server connection settings. The saved server's Docker setting is for Reproduce and is not used by this workspace: operations run on the SSH host.

Validation on macOS: 67 focused SSH, Codex, and experiment bridge tests passed, as did lint, theme checks and the renderer build. A real temporary Codex session used the read, edit and read tools on an isolated remote fixture; the fixture was removed afterward. The full suite reported pre-existing failures in experiment retry audit, translation ordering in `researchGraph.ts`, a Library tabs audit, and a local LaTeX font dependency. Desktop screenshot capture could not be completed because the available computer-use connection timed out; the composer still needs visual verification in the app.
