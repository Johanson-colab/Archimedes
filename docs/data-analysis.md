# Data Analysis 使用说明

Data Analysis 是本地 CSV/TSV 数据探索台。打开时展示 Palmer Penguins 真实示例，不会自动上传文件。右上角 **Examples / 示例** 可切换数据，**Open CSV / TSV / 打开 CSV / TSV** 可导入自己的文件。

## 用企鹅数据熟悉操作

Palmer Penguins 包含 344 只企鹅、3 个物种和 8 个字段。测量单位为 mm 和 g；原始 `NA` 缺失标记保留在数据表中。

1. 默认视图“鳍长与体重”把 `flipper_length_mm` 放在 X 轴、`body_mass_g` 放在 Y 轴，按 `species` 着色。342 条观测有完整测量，整体 Pearson r 约为 0.871。它是描述性相关，不代表因果关系，也不能替代物种内的进一步分析。
2. 点击“各物种的平均体重”。每根柱由该物种全部非缺失测量计算，悬停可看均值与样本量。
3. 点击“体重分布”。每根柱统计体重区间内的观测数，区间计数合计为 342。
4. 在左侧点 `species` 或 `sex`，查看类别频数；点数值字段查看均值、中位数、范围与缺失值。字段检查不会改变坐标轴。
5. 切换“数据表”，逐页检查原始行；每页 50 行。整个数据集有 19 个缺失单元格。

## 用天气数据练习时间分析

选择 Seattle Weather。它包含 2012–2015 年的 1,461 天观测、6 个字段。

- “四年气温变化”：按日期排序的每日最高温（°C），观察重复的季节周期。
- “降水量分布”：查看降水（mm）在零附近的集中和长尾，理解为什么不能只看均值。
- “风速与降水”：风速（m/s）与降水的散点关系，按天气类别着色。天气类别由 Vega 从原始字段派生，用于教学。

## 分析自己的数据

首行为列名。支持 UTF-8 CSV/TSV、引号内的逗号和换行；最大 10 MB、100,000 行、200 列。空值、`NA`、`N/A`、`NaN`、`null` 视为缺失。统计排除缺失数值；含有其他文本的列会被识别为分类列。

- 散点图：X/Y 为数值字段，可按低基数文本字段着色。
- 分组均值：选择分组字段和数值字段；最多显示 30 组，超出时标注未显示的分组数。
- 折线图：X 支持数值或 `YYYY-MM-DD` 日期，并按 X 排序。
- 分布：使用全部有效数值计算直方图区间计数。

描述性统计和相关系数使用全部有效数据。散点与折线超过 2,000 个点时，显示均匀抽样并标注；不是只取前 100 行。颜色最多显示 6 组，超出会标注。悬停查看点或柱的数值。

“导出 SVG”保存当前图表及颜色图例。文件和配置仅在当前页面会话中保留。

## 如何使用研究对话

在下方输入问题，会打开已有研究对话并填入可审阅的草稿，包含字段统计、绘图配置、描述性相关系数和最多 5 行样例。它不会自动发送，也不会附加完整数据集。当前版本没有自动执行 Python/R 或完整数据集的 AI 分析能力。

数据原始来源、固定版本和许可见 [示例数据说明](../src/assets/data-analysis/README.md)。
