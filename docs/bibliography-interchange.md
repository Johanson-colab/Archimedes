# Bibliography interchange

In **Library**, open **BibTeX interchange** for the current collection. Paste
BibTeX or choose a `.bib` file, inspect the preview, then import the selected
references. The preview identifies existing papers, repeated entries and citation
key conflicts within the target collection.

Reimporting a paper keeps its current metadata, PDF, indexed pages and reading
notes. Choose individual **Repair selected metadata** fields to replace existing
values. Replacing an existing citation key also requires an explicit selection.
Identifier matching recognizes DOI, arXiv and Semantic Scholar identifiers even
when their formatting changes.

Use **Preview BibTeX export** and **Download BibTeX** to move a collection into a
writing tool. Citation keys remain stable across repeated exports. This small
interchange parser supports nested braced and quoted fields and grouped author
names; expand BibTeX macro expressions before importing them. Unsupported entries
are shown as warnings instead of silently supplying incorrect metadata.
