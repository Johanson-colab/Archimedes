# Work modes

Open **Work modes** from the toolbar or command palette to choose the mode for
next messages: Conversation, Ideas, Experiments, Writing or Review. Selecting a
mode changes how new work is routed. It does not approve a scientific result or
mark earlier research as complete.

The panel follows the active session. Pin it to keep that session visible while
visiting another tool. When the pinned session is inactive, choose **Open pinned
session** before changing its mode. The existing panel position and pin settings
are preserved.
