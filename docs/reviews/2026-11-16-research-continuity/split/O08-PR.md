Structured reproduction file actions can currently follow a checkout symlink and read or overwrite a file outside that checkout. This change validates the actual Docker-host read target, rejects linked write components/final files, and checks SSH path components before running the file operation. Ordinary nested UTF-8 files, spaces and apostrophes remain supported. Structured reads over 2 MiB fail explicitly rather than returning an apparently complete document.

This is an independent split from [the closed original PR](https://github.com/Johanson-colab/Archimedes/pull/336), following [the request for separate PRs](https://github.com/Johanson-colab/Archimedes/pull/336#issuecomment-6912591490), based on upstream main `1f4b375`.

This is nonvisual.
