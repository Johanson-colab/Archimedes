**Review current PDF** prepares the saved manuscript's verified build as a separate simulated-review input. The review records its project/folder, source version and PDF hash, offers a return to the source file, and can append a selected finding with its page/quote to a separate revision discussion. Existing unsent research drafts are preserved.

A real review run retains its build input. Explicit deletion releases only that run's reference, including when manuscript sources have been removed; cancellation retains history and other consumers' references remain intact.

This single-feature review targets `codex/manuscript-review-base` (`d077fe18`): [existing manuscripts](https://github.com/Johanson-colab/Archimedes/pull/348), [build receipts](https://github.com/Johanson-colab/Archimedes/pull/347), and [session drafts](https://github.com/feiiiiii5/Archimedes/pull/3), with their [data-store ownership](https://github.com/Johanson-colab/Archimedes/pull/341) and [execution-context](https://github.com/feiiiiii5/Archimedes/pull/1) prerequisites. The review base is an actual ancestor, so the three-dot diff contains only this feature.
