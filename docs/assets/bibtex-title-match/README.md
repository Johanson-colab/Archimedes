# Same-title BibTeX import

The two captures use the real Bibliography dialog in Electron with a 1280 × 870 Paper viewport and a disposable SQLite library. Both start with Fei Chen’s 2022 “A Shared Title” and preview Maya Martin’s 2022 reference with the same title and a different DOI.

The upstream baseline offers to modify the existing record. With the fix, the import previews a new paper and keeps the original row separate.
