# Model registry in Settings and the composer

These screenshots show the compiled Archimedes desktop app on macOS at 1560 × 980 in the Paper and Charcoal themes. Both builds opened fresh local workspaces with the same two legacy model configurations. The fixture used only a loopback API and dummy credentials. The before build is the provider-headers branch at `1bca636`. The after build includes the registry changes and saves a model context value of 24,000 and an output limit of 321.
