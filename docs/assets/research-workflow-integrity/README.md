Final desktop validation also completed these normal workflows:

- Reopen a saved eight-row CSV analysis, continue in its historical-root conversation, and preserve an existing draft.
- Insert a PNG into an existing multi-file manuscript, compile it, and pass the resulting version to review/slides and a revision conversation.
- Deliver a delayed reply to its original data workspace while another workspace is selected.
- Export 17 project files, restore into a new project/directory in another data workspace, continue the old manuscript and analysis, then map/save/reopen a CSV numerical comparison.

The OS capture tool returned window thumbnails for the later analysis, writing and discovery capture attempts; those thumbnails are excluded. The completed operations above are recorded as behavioral validation, not additional screenshot pairs. Models used local test responses; these images make no scientific-result claim.
